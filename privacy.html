Privacy Policy

Application: Rclone Backup D
Owner: Personal use only
Last updated: 2026-11-02

1. Overview

Rclone Backup D is a personal, single-user automation tool that uses the Google Drive API to back up files from a local drive to the owner's personal Google Drive storage. It is not a commercial product and is not available to the public.

2. Data collected

This application does not collect, store, or share any personal data. It accesses only files that it creates or has previously uploaded to Google Drive (scope: drive.file). No data is transmitted to third parties.

3. OAuth tokens

OAuth 2.0 tokens obtained during the Rclone authorization flow are stored locally on the owner's personal computer and are never shared with third parties.

4. Contact

This application is for private, personal use only. There is no public support channel.
